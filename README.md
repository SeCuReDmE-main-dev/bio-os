# ⚠️ Bio-OS: Experimental Synthetic Biology Simulator

DISCLAIMER: NOT FOR LAB OR MEDICAL USE.
This is a strictly educational and experimental software project.
It is a computer science thought experiment demonstrating how a Fail-Closed architecture could be applied to biological code.

## The Thesis
If an AI hallucinates writing JavaScript, a website crashes.
If an AI hallucinates writing DNA, the consequences are catastrophic.

Bio-OS acts as an in-silico sandbox and cryptographic leash for AI-generated DNA sequences.
